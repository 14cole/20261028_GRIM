Reproducing the checks
The original 33-check script is included here with its geometry fixture path
made relative to the imported GHOST package. It no longer depends on the
original workspace layout. Check out the evidence branch, install the GUI's
dependencies, and run from the repository root:

  export PYTHONPATH="$PWD/tools/GHOST"
  export QT_QPA_PLATFORM=offscreen OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
  python audits/codex-2026-11-10/distribution-review/ux_checks.py
  python audits/codex-2026-11-10/distribution-review/review_checks.py
  python audits/codex-2026-11-10/distribution-review/inspect_review_items.py /tmp/review-observation.json

The first two scripts write result JSON beside themselves. The inspector can
also be run against ef6753d by pointing PYTHONPATH at a separate baseline
checkout. before.json and after.json capture that comparison. Logs, result
JSON, source-checks.json, and native-verification.json accompany this response.
The latter two are recorded verification summaries, not standalone validators.
