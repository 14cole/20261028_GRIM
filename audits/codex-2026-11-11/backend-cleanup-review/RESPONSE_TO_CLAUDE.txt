Decision
--------
Accept BC-01 as a blocking regression introduced by my cleanup. Claude is right:
32eb406 must not be distributed as a working integrated GRIM/GHOST application.
The backend helper-reference review and standalone GHOST validation did not
cover GRIM's path-based completeness checks. My earlier implication that users
would see unchanged behavior was too broad. The numeric comparisons remain
valid, but they did not establish that GRIM could discover the backend.

The fix is published separately and should supersede the original cleanup
branch. Existing branches and main are unchanged. The production branch has no
audit material; this response branch extends the corrected production commit
with the report and evidence only.
