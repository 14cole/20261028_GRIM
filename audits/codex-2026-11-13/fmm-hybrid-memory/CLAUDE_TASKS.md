# Requested independent work and review

Start with `HANDOFF_FMM_HYBRID_MEMORY.md`, then reproduce the evidence checks in `REPRODUCTION.md`. This branch contains research only. Treat the measurements as case-specific; do not substitute product timings for complete solve times.

## Review Codex's work

1. **Panel partition and nodal aggregation.** Audit `hybrid_galerkin.py` and `nodal_block.py`. Each original FMM near panel pair must appear exactly once. Panel clusters may share nodal IDs, so their contributions must be summed at application, not deduplicated across blocks. Verify a queried nodal row includes only its supporting panels inside that cluster. Test arbitrary node numbering, disconnected loops, corners, shared endpoints and multiple incident panels. The implementation is P1-only.
2. **Streamed CSR and transpose sharing.** Check chunk boundaries, duplicate accumulation, 32-bit column indices, empty/degenerate inputs, buffer lifetime, and that K/K' share immutable values. Production integration needs explicit retained and construction memory budgets; this bounded research driver is not a production allocation guard.
3. **Symmetric storage.** S and W are complex symmetric, not Hermitian. Check the diagonal subtraction and complex lossy cases. Confirm that selecting one triangle does not silently hide a material quadrature asymmetry. The two directions of an adaptive integral can stop differently; the existing thin-gap discrepancy is not solved by storing half the matrix. Independently design an error policy for the requested assembled operator, including the Maue W contraction, rather than relying on K incidentally forcing extra S refinement. The joint result is closer at the tested entries, not a universal exact reference.
4. **Compression error policy.** The first panel-local prototype used 1e-11 relative local Frobenius targets and showed error growth in W. The nodal variant uses 1e-13 in the principal runs. Audit sampling, rank rejection, dense fallback and cancellation after assembly. In particular, the current half-dimension rank cap is on the shared S/K/W skeleton before per-component recompression; test whether it rejects economical small blocks. Accept by final payload and qualified error, with an explicit workspace cap. The nodal block oracle currently assumes unique row/column query indices; retain that private contract or explicitly support repeated indices in a public interface. A local tolerance and sampled-product agreement are not a deterministic whole-operator certificate. Recheck the known tree-depth transition with the unchanged FMM far evaluator.
5. **Complete-solve interpretation.** The TE/TM checks deliberately use the same streamed-near ILU and dense-reference scaling for both operators. Dense references and auxiliary near matrices are live. These are accuracy/convergence comparisons, not demonstrations of standalone hybrid solver capacity.
6. **Native tuning wrapper.** Independently verify the 26-argument `hfmm2d_ndiv_` ctypes signature, default 32-bit integer ABI, `idivflag=0`, `ifnear=1`, output normalization/conjugation, and equivalence of ndiv=25 to the library's default at eps=1e-12. Reproduce the stage profiles and leaf-size tradeoffs before selecting a policy.

## Investigate independently

**Highest priority: a scalable preconditioner without reconstructing the full FMM near matrix.** Start from the nodal hybrid's exact local blocks and compressed separated blocks. Compare a hierarchical approximate inverse, multilevel Schwarz/local factors with a coarse correction, and the present near ILU. Include both TE and TM, loss, thin layered bodies, and increasing electrical size. Measure factor construction peak, retained factor bytes, iteration counts, true residuals and complete field errors. Do not add inverses of local blocks and assume they form the global inverse.

**Panel-moment far adapter (independent implementation requested).** The current point adapter stores E, Eout and dip at eight Gauss nodes per panel. Test preprojecting source and target plane waves onto the two P1 endpoint functions; normals are constant on a linear panel, and derivative moments can use the sum of endpoint moments divided by panel length. `panel_projection_proof.py` checks the algebra and accounts for payload, but does not implement or benchmark a full projected operator. Build these moments in bounded tiles from the start: constructing the old phase arrays and then deleting them would retain the old peak. Preserve panel/leaf assignment, complex-k signs and all four operators. Skip unused far-phase storage entirely in the all-near fallback. This can complement the local hybrid rather than replace it.

**Native adaptive-wideband route.** Use the stage profiles to identify what can actually be reused between applications. The current library rebuilds its tree and work arrays each call, but tree reuse alone may address only a small fraction of time. At ndiv=25 in the 2k real-k case, the library’s multipole-to-local stage accounts for roughly 45% of S and 54% of W call time. In `src/helmholtz/hfmm2d.f`, electrically smaller boxes call `h2dmploc` separately for each list-2 interaction, while the high-frequency path precomputes diagonal shifts. Investigate reusable low-frequency translation coefficients/matrices as well as a persistent tree and source/target evaluation data. Distinguish coefficient construction from the unavoidable translation application cost; eliminating the entire measured stage would only be an upper bound on speedup. Compare its RAM/time with the Python reusable FMM plus nodal local compression at identical accuracy. Resolve the inherited upstream root-license/source-header inconsistency before distribution work; this branch ships no external native library.

**Reduce hybrid construction queries.** The cross-approximation routine can ask for more panel coefficients than the original near matrix contains because samples and probes revisit supporting panels. Investigate bounded per-block caching, shared row/column queries, and grouping admissible partners. Also compare compressing a panel-local factor first and then summing its rows/columns onto shared nodes: if the local approximation is U V, nodal assembly gives (Pᵀ U)(V Q). This may avoid the nodal oracle’s repeated support-panel queries, but the assembled error must be checked and the factors may need recompression. Keep singular/very-near integration exact. Report setup savings and additional cache peak, not just the final low-rank payload.

**Qualification beyond this study.** The 512-panel gap/coated/graded full-matrix nodal-hybrid cases accepted no low-rank blocks: they validate partition/scatter and integration, not compression of layered geometry. Independently force compression to be active, for example with 2,048 or more panels on concentric contours, and record the accepted compressed-pair fraction. Run actual multi-region dielectric/PEC coated solves, independently selected near-resonant geometries, severe grading, and higher electrical sizes. The concentric-contour operator test is not a complete coated-body solve. Separate fixed-frequency mesh refinement from electrical-size growth at fixed panels per wavelength. Include analytic cylinder or manufactured references alongside dense discrete references. Compare 1/16/181 incident angles against production Dense and Compressed under the same final accuracy gates. This study does not establish a 32 GiB model-size guarantee.

**Keep non-FMM alternatives active.** Continue direct Compressed improvements, selective precision with refinement, and disk-backed residual storage as independent paths. A shared user-facing Automatic mode can select among numerical engines. The present evidence does not justify deleting Dense or Compressed.

## What a useful response should include

Pin the source commit, state any changes to tolerances or quadrature, retain complete field arrays, and separate new measurements from extrapolation. For each proposed improvement, report both the successful and failing cases, setup plus solve time, peak process RAM, retained arrays/factors, and the final physical/numerical checks. Prioritize whether the evidence supports production integration, another bounded prototype, or stopping a direction.
